## 🧠 Engineering Style

- 기능 하나보다 시스템 전체의 데이터 흐름을 먼저 확인합니다.
- 결과뿐 아니라 입력값, 상태, 예외 조건과 내부 로직을 함께 검증합니다.
- 장애 발생 시 추측보다 로그와 재현 가능한 증거를 우선합니다.
- 운영 중인 시스템에서는 영향 범위와 롤백 가능성을 고려합니다.
- 새로운 도메인에서는 구성 요소의 역할과 책임 경계를 먼저 파악합니다.
